# Branching Screenplay
Branching Screenplay (or Branching Scenario) is an extended form that adds new features to the standard Screenplay.

## Overview
The goal is to help writers create Screenplay scripts that align with gameplay interactions.

## Version
Branching Screenplay (Scripting) can be improved in terms of readability and ease of writing.  
**Current Version: v0.1**

## Screenplay (Scenario)
Some Screenplay elements are listed below.

**Screenplay Elements:**
- Scene Heading / Slugline
- Action / Scene Description
- Character Name (Extensions)
- Dialogue
- Parenthetical
- Transition

### Screenplay Elements
A typical screenplay looks like this. The Transition section also includes entries such as "CUT TO:", "FADE OUT." and so on.  

<p align="left">INT./EXT. SLUGLINE - SCENE HEADING - DAY</p>
<p align="left">Action</p>
<p align="center">CHARACTER</p>
<p align="center">(Paranthesis)</p>
<p align="right">TRANSITION:</p>

### New Transitions
Transitions are extended by adding "CONDITION:" and "CHOOSE TO:". The target scene of the transition is then specified by writing "SCENE NUMBER" (e.g., "1").  

<p align="right">CONDITION:</p>
<p align="right">- OPTION 1 -> SCENE NUMBER</p>
<p align="right">- OPTION 2 -> SCENE NUMBER</p>

<p align="right">CHOOSE TO:</p>
<p align="right">- OPTION 1 -> SCENE NUMBER</p>
<p align="right">- OPTION 2 -> SCENE NUMBER</p>
<p align="right">- OPTION 3 -> SCENE NUMBER</p>
